# Book 与分类文件夹的知识范围选择

日期：2026-10-21。本次完成多 Book、多分类及混合选择，覆盖笔记、Agent、全库检索、阅读问答、后台 Book 问答和学习资料。文件夹使用现有 Book 分类，包含子分类；在线 Book 和上传文件型 Book 均可选择。

## 使用方式与入口

点击范围选择框，勾选 Book 或分类文件夹，再点击“应用知识范围”。分类目录显示各文件夹的就绪数量；“全部 Book”视图可以跨分类勾选，切换视图保留已选项。搜索支持 Book 标题和分类名称。

| 入口 | 选择范围 | 数量与空选语义 |
|---|---|---|
| `/admin/assistant` → Agent 授权知识 | 多本 Book、多分类、混选 | 1–50 本 |
| `/admin/assistant` → 合并来源 | 多本 Book、多分类、混选 | 2–10 本 |
| `/admin/knowledge` → 指定 Book | 多本 Book、多分类、混选 | 最多 5000 本；留空按页面所选的我的知识 / 公开书库全库检索 |
| `/books/{id}` → 右侧问答知识范围 | 可选择我的知识或公开书库中的多本 Book / 分类 | 最多 5000 本；默认或“恢复仅当前 Book”只检索当前 Book |
| `/admin/books/{id}` → RAG 问答 | 可选择我的知识或公开书库中的多本 Book / 分类 | 最多 5000 本；留空只检索当前 Book |
| `/admin/books/{id}` → 笔记助手关联检查 | 多本 Book、多分类、混选，排除当前 Book | 最多 100 本；留空沿用全部就绪关联资料 |
| `/admin/learning` → 学习资料 | 多本 Book、多分类、混选 | 1–50 本 |

“文件夹”是知识库内的分类，例如“编程 / Python”，不是本机磁盘目录。分类可在 `/admin/taxonomy` 管理；Book 创建或编辑时设置所属分类。一份上传文件仍对应一本 Book。

## 范围与权限

- 勾选分类会选入其中及其子分类内所有可选 Book；也可以展开分类后只选部分 Book，或增加其他分类中的独立 Book。
- 未就绪、索引失败或当前修订未完成索引的 Book 显示原因并禁止选择。超过该入口的数量限制时显示提示，保留上一次有效勾选，不自动截断。
- 目录最多返回 5000 本可访问 Book 的元数据，不携带正文。超过上限会明确提示；此前选择器受首屏 50 本限制的问题已解除。
- 我的知识仅包含有权访问的资料；公开书库只包含已发布内容。匿名用户只能使用公开书库，服务端强制公开范围，并在回答完成前再次核验发布状态、修订和索引。
- 应用时将分类解析为这一刻选中的 Book ID 集合。以后分类内新增、移出或删除 Book 不会自动改写已有计划或会话；需要重新选择范围。权限、发布与修订变更仍由执行接口复核。
- 阅读页按精确 Book 集合和公开 / 私人范围分别保存对话，切换范围不会混用旧回答；恢复当前 Book 可回到它自己的对话。已登录用户沿用持久化会话，匿名跨 Book 问答仅保留当前页面会话。
- 问答保持“结论 + 简短论据出处”，点击链接可定位对应 Book 的来源；后台跨 Book 问答不再把其他文件的引用误指向当前 Book。
