# Book_Agent 完整功能验收清单

日期：2026-10-21。本清单对应当前源码和本轮测试，包含最初 74 项需求的实现状态，以及 100 条可操作的验收项。测试自验结果不代替用户最终验收；请在验收后勾选对应项。

本轮结果与修复说明见[整体测试与优化报告](整体测试与优化报告.md)。阶段 5 知识图谱已按用户决定移除，当前版本保留阶段 1–4 和阶段 6。

知识范围功能补充 S01–S10：多本 Book、分类文件夹（含子分类）、混选、阅读问答范围切换及各入口一致性，见[知识范围选择与验收](知识范围选择与验收.md)。范围增量包含 100 条基础验收和 10 条增量验收，该轮自动化共 139 项通过。

后续上下文管理补充 C01–C08，见[上下文管理与验收](上下文管理与验收.md)：滚动意图摘要、旧问题召回、权限失效、Agent 步骤记忆和长文处理。最新自动化为 Java 40 / Python 82 / 前端 45，共 167 项通过；前述 139 项为范围增量时的历史记录。

## 5. 已知边界及人工专项

- 文件 ≤20MB、正文 ≤100 万字符；扫描 PDF 需先 OCR。复杂 PDF 版式以解析文字为主，不还原原页面排版。
