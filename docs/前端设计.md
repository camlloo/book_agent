# 前端设计与流程

文章与 Book 统一命名为 Book。前台依据用户提供的三栏截图设计，后台保留既有蓝白管理界面。

## 阅读空间

52px 顶部工具栏下方为左侧 260px 目录、中间弹性阅读区、右侧 350px 对话。灰色 #f6f7f8 面板与白色纸面用 #e3e5e8 细线分隔；正文 #252b34、活动态 #365ec9。标题用 Noto Serif SC，界面与正文用 Noto Sans SC，代码用 Cascadia Code / Consolas。阅读正文约 720px 限宽。

左侧展示分类、标签、搜索、分页书库和自动提取的 h1–h3 章节。中间展示净化 Markdown；文件型 Book 读取原文件解析结果并保留 PDF 页码，不能拼接重叠分块。右侧限定当前 Book，展示历史对话；来源以句子旁的简短超链接仅显示 Book / 文件名与页码，不再显示回答末尾的折叠列表。点击定位并标出原文，复制链接或刷新可以恢复出处；手机同时关闭对话抽屉。输入框固定在面板底部。左右独立收起，保留正文滚动位置与本次页面会话；桌面面板偏好本地保存。

760px 及以下内容优先，侧栏转为互斥抽屉，配遮罩、关闭按钮、Escape 与 Tab/Shift+Tab 焦点约束。直接 /ask 自动展开并聚焦对话抽屉。1440×1000、1280×900、390×844 通过 Chrome/Playwright 验证。

首页 / 自动打开最近发布的 Book；/books/:id 优先公开读取，404 时在有登录凭据的情况下读取私有内容；/books 为需登录完整书库。/articles/:id 解析历史映射。/ask 使用同一阅读组件并要求先选择 Book。匿名仅访问 PUBLISHED，草稿和下线需 ADMIN。

## 管理与写作

后台采用 232px 淡蓝侧栏、开放式表格、Element Plus 控件与 Lucide 图标。主入口 /admin/books，另有写作助手和分类标签；旧文章管理路由重定向或解析到 Book。列表展示来源模式、发布状态、索引状态、分类标签与阅读入口。

新建以在线编写/文件上传两种模式添加 Book。在线提供 Markdown 编辑、对照、预览与图片上传；文件模式一份 PDF/DOCX/TXT/MD 直接创建 Book，原文件可下载和按版本替换。两种模式都自动向量化。编辑页支持分类标签、保存、发布与下线；发布与索引状态独立，未就绪禁止问答。

写作输入主题→提纲确认→扩写确认→润色对照确认→新 Book 草稿并自动索引，不覆盖原文或自动发布。检查点和编辑器保护未确认/未保存内容；取消丢弃会保留输入。删除、发布、下线、取消任务使用说明后果的确认。手机管理导航保持可达，表格在自身滚动，编辑对照上下排列。

## 状态与安全

加载、空库、错误与模型失败都有明确提示和可执行入口，不使用假数据补位。Markdown 净化，代码与表格自身横向滚动。键盘焦点可见，支持跳到正文与减少动画。回答以当前证据为依据，无相关原文时说明依据不足；最多六条历史消息辅助追问。实际视觉规范见 DESIGN.md，截图及验收结果见 .impeccable/review。

问答统一显示“结论”和“论据”，沿用 Markdown 加粗标签与段落，不增加来源清单。结论直接说明结果或无法确定；论据仅显示出处链接，使用真实 Book / 文件名和页码；同一文件的同一页不重复列出，不解释或重复原文。无检索结果显示两部分的依据不足说明。


## 个人空间扩展（2026-10-15）

沿用蓝灰工作区和三栏阅读。新增 /register、/admin/knowledge、/admin/imports、/admin/settings；Book编辑页增加历史版本、分享、来源、索引策略和导出。全库页面左侧为范围与历史对话，右侧为答案和原文搜索；桌面并排、手机纵向，管理导航可横向滚动。已保存对话与Book由服务端同步读取，切换设备需登录同一账号。修改前先保存正文，避免自动整理或恢复历史覆盖未保存输入。
