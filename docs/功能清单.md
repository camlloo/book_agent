## 阶段 4：笔记与 Agent（2026-10-18）

- Book 笔记助手可生成标题、简介、分类与标签建议；可预览正文润色，确认后形成新修订并重新索引。
- 对其他有权访问的 Book 检查可能重复、内容冲突或需要核实之处；每条发现都要求引用真实检索来源，没有证据时不下判断。
- 可按学习水平解释当前 Book 内容、检索关联知识；合并多本 Book 时先生成带来源的预览，再由用户确认是否另存成新的私有 Book。
- Agent 可针对明确目标自动生成计划，也可在创建时手动设计 1–6 个步骤；只有检索步骤访问 RAG，后续总结/对比/起草/校对使用此前检索来源与生成内容。
- 用户可编辑、插入、移动或移除计划步骤，也可从指定步骤重跑后续；旧结果与现有检索来源冲突时提供保留来源的修复入口，依赖顺序由后端校验。
- Agent 工具只开放检索、总结、对比、起草和校对；起草产物只能由用户确认后保存为新的私有 Book 草稿，不覆盖源内容或自动发布。
- 个人长期偏好按用户隔离，并仅影响表达方式；工作台根据个人 Book 的简介、分类标签与索引状态提出整理建议。

本阶段未实现自动发布、后台自主执行或绕过人工确认的编辑；重复检测以检索片段为边界；主动建议目前由 Book 元数据和索引状态规则生成，不包含学习进度、间隔复习或外部推送。入口、接口、验证结果及截图见[阶段 4 功能与验收](阶段4功能与验收.md)。

## 3. Book 创建、编辑与发布

### 在线编写

- 保存标题、简介、Markdown 正文、分类与标签。
- 编辑、对照、预览三种模式，预览执行 Markdown 净化。
- 上传配图并插入正文；图片保存到 MinIO `images/`。
- 保存正文后自动建立或更新向量索引。
- 使用 revision 防止过期版本覆盖当前内容；冲突时保留用户输入。
- 离开、刷新和关闭页面时保护未保存修改。

### 文件上传

- 支持 PDF、DOCX、TXT、MD；上传一份文件直接创建一本 Book。
- 原文件就是 Book 内容来源，不是其他 Book 的参考附件。
- 上传型 Book 可编辑标题、简介、分类与标签，下载或按版本替换原文件。
- 文件类型、文件头、大小、SHA-256 校验；同内容避免重复索引。
- 替换原文件后更新修订、重新索引并后台清理旧对象与分块。
- 旧版在线 Book 的历史附件保留兼容访问，主流程不再添加参考附件。

### 发布与访问

- 发布状态为 `DRAFT → PUBLISHED ⇄ OFFLINE`，保存与 AI 写作默认形成草稿。
- 已发布 Book 可匿名阅读；草稿与下线内容要求所有者或授权用户。
- 文件型 Book 发布前要求当前修订索引就绪；发布与索引状态分别记录。
- 浏览量原子递增，首次发布时间保留；浏览与索引不改写内容更新时间。
- 删除后立即禁止业务访问，再异步清理对象与向量。
- BookService 统一读取、问答与下载签名的前后修订和发布校验；公开操作要求完成校验时仍为PUBLISHED，同一修订先下线再发布的撤回历史无法识别。
- 原文接口固定返回 BookReadVO（BookVO book、sections数组），文件解析结果必须为数组。

## 4. 阅读与出处交互

- 桌面左侧书库分组、分类/标签筛选、搜索与分页，自动提取 h1–h3 正文章节。
- 中间显示在线 Markdown 或原文件解析文本，PDF 保留页码；不拼接重叠的向量分块作为正文。
- 右侧默认为当前 Book 对话，可选择多本 Book 或分类问答，恢复仅当前 Book 时回到独立对话；底部固定输入框。
- “最近”列出当前用户的历史对话，可搜索标题并恢复所选会话原来的 Book 集合、公开 / 私人范围及模式；同一范围可新建多段独立对话。新建不会删除已有记录，删除需在列表中二次确认。已登录会话通过地址中的 conversation 参数恢复，匿名历史入口提供登录引导。
- 左右面板可分别收起，保留阅读滚动位置与当前页面会话；桌面偏好本地保存。
- 手机使用互斥抽屉、遮罩、Escape 关闭、Tab 焦点约束；点击出处后关闭对话并定位正文。
- 出处仅以 Book / 文件名和可用页码的超链接显示，不在回答末尾展示折叠列表。
- 点击或 Enter 可标出相关原文并转移焦点；文件长文本可以标记具体句子。
- 引用链接携带原文定位信息，直接打开和刷新可恢复出处；无法精确匹配时退到所属页段。
- 支持 Markdown 表格/代码局部滚动、可见键盘焦点、跳到主要内容和减少动画偏好。
- readerSession 捕获目标 ID，采用读取/目录代次与会话代次，迟到原文、目录、章节、下载和回答不会污染新状态；问答仍归属发起时的Book会话。
- 认证失效清理私有原文、目录与聊天，保留公开内容；旧token的迟到401不注销新登录。

## 5. RAG 与问答

### 索引流程

1. 在线保存、上传创建、原文件替换或重新索引，在 MySQL 持久化索引任务。
2. Java 调度器领取任务，通过修订与 runId 防止旧结果覆盖新内容。
3. Python 通过 MinIO 签名链接受限下载并校验大小与 SHA-256。
4. 解析文本型 PDF、DOCX 段落/表格、TXT 与 MD；文本支持 UTF-8 / GB18030。
5. 使用中英文分句器，按 400 token 分块、64 token 重叠。
6. 批量调用嵌入模型；稳定分块 ID 使未变化内容可复用向量。
7. pgvector 持久化文本、向量、文件名、页码与修订；使用 HNSW 检索。
8. 显示 QUEUED / RUNNING / READY / FAILED、错误原因与重新索引入口。

### 回答规则

- 使用向量与中文关键词混合召回，检索严格限定当前 Book 与当前就绪修订。
- 当前版本未就绪时禁止问答；生成后重新核验修订，公开接口再核验发布状态。
- 查询嵌入等待不占Book search事务；模型返回后，在同一REPEATABLE READ只读快照复核状态并读取向量、关键词候选。
- 支持最近最多六条成功历史消息，先前用户问题辅助追问召回。
- 回答固定为“结论”和“论据”：结论直接回答，论据只保留简短出处链接。
- 服务端校验结构与引用，剔除论据中的解释/摘录；同一文件的同一页去重。
- 格式或编号错误允许一次格式重试，仍失败明确报错。
- 没有相关片段时不调用聊天模型，明确无法确定，论据为“未检索到相关出处”。
- 当前原文是依据；历史回复和资料中的指令不作为新的事实或系统指令。

### 模型与存储

| 项目 | 当前实现 |
| --- | --- |
| 主聊天渠道 | DashScope OpenAI 兼容地址，`qwen3.8-flash` |
| 默认嵌入 | DashScope `text-embedding-v4`，1024 维 |
| 配置方式 | `DASHSCOPE_API_KEY` 用户变量；项目配置不包含明文密钥文档 |
| 备用渠道 | DeepSeek、Qwen、GLM、Ollama 的配置、重试与渠道回退 |
| 可选本地嵌入 | FastEmbed `BAAI/bge-small-zh-v1.5`，512 维 |
| 业务原文与任务 | MySQL |
| 上传原文件与配图 | MinIO：`books/` 私有，`images/` 匿名只读 |
| 文本分块与向量 | PostgreSQL / pgvector，Docker 持久数据卷 |

持久数据存储在本机基础设施；远程模式下文本分块发送给嵌入服务，检索片段发送给聊天服务。

EmbeddingSpace 按实际生效URL、模型、维度共享身份；保持既有Book哈希与向量命名空间，不因身份实现收敛重建原Book向量。仅内部 /internal/ask 保留显式文章快照检索，不代表Java公共问答提供全站快照模式。

## 6. AI 协作写作

- 根据主题与写作要求创建任务，可选择当前就绪 Book 作为知识源。
- 提纲、扩写、润色各阶段均由作者查看、修改并确认。
- 润色支持原稿与改写对照，历史检查点持久化保存。
- 任务排队、执行、待确认、完成、失败与取消状态可见。
- 支持取消、失败重试、删除终态任务；已生成 Book 不随任务删除。
- runId 与条件更新防止重复确认、过期回调或取消后的结果覆盖。
- 未确认修改受切换任务、离开页面和刷新保护。
- 最终确认另存新 ONLINE Book 草稿并自动索引，不覆盖源 Book、不复制源原文件、不自动发布。
- 旧文润色字段和历史任务结果保留兼容能力。
- 内部 /internal/write 的book_id/book_revision必须成对传入；缺失一项422，索引版本冲突409。

模块边界分析与接口取舍见 [架构评估与优化 RFC](架构评估与优化RFC.md)。

## 9. 当前边界

- 支持个人 USER 账号与 Book 分享；尚无组织团队、SSO、独立企业租户管理。
- 单本问答与全库问答并存；全库检索限定有权且索引就绪的 Books。
- 登录后的对话持久化，刷新可继续；匿名对话保留于页面内存。登录后的两个聊天界面（阅读页对话与知识工作台）支持 SSE 流式预览，完成后以校验过的完整结果替换；匿名与单 Book 轻量问答仍为整段返回。
- 支持文本型 PDF；尚无 OCR、扫描 PDF 直接识别、Excel / PPT 原文件解析。
- 原文阅读主要展示解析文字，不是还原 PDF 页面排版的阅读器。
- 正文上限 100 万字符，原文件 20MB，单文档解析 200 万字符，PDF 1000 页，Book 10000 分块；DOCX 有条目与解压大小限制。
- 文件签名有效120秒且不能即时撤销；下线阻止新的公开请求，完成校验要求仍PUBLISHED，但不识别同修订先下线再发布的撤回历史。
- 删除存储对象与向量异步完成；业务访问先失效，后台失败重试。
- 当前索引与并发配置面向单实例；尚未实现多实例任务调度与高可用部署。
- 备用模型/本地嵌入属于可配置能力，不代表所有渠道都做过真实质量验收。
- 学习水平使用学习者自评和打卡记录估计；当前不生成正式能力测验、间隔复习计划或自动推送提醒。
- 已提供部署模板，尚未执行公网部署或非 Chrome 浏览器完整验证。
