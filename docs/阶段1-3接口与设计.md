# 阶段 1–3：个人空间、采集与全库检索

更新：2026-10-15。Java 保持业务事实与访问授权的唯一来源，Python 执行采集、解析、嵌入、检索与生成。

## 数据与权限

使用追加表 `book_owner`、`book_share`、`task_owner`、`category_owner`、`tag_owner` 记录个人数据范围。旧内容幂等归入已有管理员空间，不重编号、不删除旧 article 档案。分类标签在个人空间可同名，旧表唯一键保持兼容，真实显示名称保存在所有权表。

USER 可创建管理自己的知识；预留的 READER 账号保持只读；ADMIN 有系统维护权限，但“我的 Book”和全库检索默认仍按拥有/被分享范围筛选。共享角色 VIEWER 可阅读、问答与下载，EDITOR 增加正文、文件和索引编辑；发布、下线、删除与分享由所有者或系统管理员操作。写作任务与对话记录属于个人，不能通过猜测 ID 读取他人的对话。

公开读取仍只接收 PUBLISHED。私有读取、问答、下载和全库检索在远程处理后复核权限及修订，撤销分享不会返回迟到的结果。已经签发的原文件链接仍可在120秒有效期内使用。对话历史中的来源一旦不再可读，相关助手回答隐藏；旧回答不作为新事实依据。

## 版本与备份

`book_revision` 保存不可变内容快照，`book_revision_file` 关联当时的原文件。恢复历史生成新修订，当前发布状态保持；不修改历史版本。历史所需的 MinIO 对象保留到整个 Book 删除，避免版本存在但文件已清理。升级以前未保存过的历史无法补回。

完整备份为 `manifest.json + files/` ZIP，包含本人 Books、分类标签、来源、历史及原文件。备份排除密码、登录令牌、模型密钥和旧分享授权；恢复创建新的私有草稿与新的索引任务，原内容保留。文件按大小与 SHA-256 核验，限制 ZIP 条目、展开大小和路径；不把压缩包解压到任意磁盘路径。备份/恢复同一时刻限一个操作。

备份边界：500 本、100MB 压缩、256MB 展开；单一 Book 原文件仍为 20MB。数据与对话保存在服务端，可通过同一账号在不同设备读取；当前为在线访问与刷新恢复，没有离线合并或实时共同编辑。

## 采集

`knowledge_import` 保存 WEB/REPO 任务、所有者、目标修订、状态、执行标识与错误。采集在独立线程执行，网络等待不占业务提交事务；完成提交重新检查 runId、取消状态、用户和内容版本。中断的任务可重试。

WEB 提取静态 HTML 的正文、标题、列表和代码，移除导航、脚本与表单。每个重定向重新解析并核验公网 IP，连接固定到已核验 IP，TLS 继续验证原主机，避免内网访问和 DNS 重绑定；跨站重定向不携带仓库令牌。

REPO 支持 github.com、gitlab.com 项目，选择默认分支、指定分支或提交以及可选子目录。读取 API 返回的不可变提交快照，不运行代码；保存目录、可读源文件和清单推断的技术栈。忽略依赖/构建目录、二进制、符号链接和常见凭据文件；超过 1000 个选中文件、80 万源码字符或 80MB 展开内容时明确失败。深层 AST、调用图与代码 Agent 属于后续阶段。

公开仓库无需令牌；私有仓库需服务端 `GITHUB_TOKEN`/`GITLAB_TOKEN` 具备权限。Windows 用户环境变量由启动脚本桥接 WSL，不写入命令参数。仅令牌转发逻辑已用替代传输验证；真实联网验收使用公开仓库。

来源保存在 `knowledge_origin`。同一用户再次采集同一来源会更新原 Book；散列未变化时记 UNCHANGED，不创建重复内容。可选自动分类与标签由模型生成并存入个人空间；现有 Book 可查看建议后应用。按来源、创建日期、主题分类和标签筛选。

## 全库 RAG

Java 每次生成当前用户有权且修订就绪的 `{book_id,revision,title}` 集合，Python 只在这个集合中取候选，查询结束 Java 再复核。默认最多 5000 本，可选定 Book 缩小范围。没有先查询全库再在界面隐藏私有结果。

保留 pgvector HNSW；追加 PostgreSQL `tsvector`/GIN 全文索引，中文双字词和英文标识符建立检索词，原文精确子串匹配参与排序。支持 hybrid / semantic / keyword / fulltext，融合采用 RRF。候选可调用 DashScope `gte-rerank-v2` 重排；不可用时显示融合排序回退，不伪称模型重排成功。关闭方式：`RERANK_ENABLED=false`。

新增语义切片：按最多 180 token 生成语义单元，用相邻嵌入相似度选择边界、最多合并两个单元，再以 400 token 硬限制切片；不跨文件/页码合并。新任务默认语义策略，已有索引保留；“采集来源→索引策略”可在 semantic 与 sentence 间重建。语义策略会增加边界嵌入调用量。

问答、总结和对比采用同一“结论 + 简短出处”契约。总结/对比优先覆盖不同 Book，回答基于实际召回片段，不能当作对全部正文的完整审计。追问用最近历史改写检索问题，历史回答不作为资料。对话和消息分别保存在 `knowledge_conversation`、`knowledge_message`，执行标识阻止重复并发发送；失败消息不作为后续上下文。

## 新增与扩展接口

Java 仍使用 Result 外壳；下载接口直接返回二进制文件，错误仍为 Result。所有个人接口要求登录；来源权限由业务服务再次确认。

| 方法 | 路径 | 请求与行为 |
| --- | --- | --- |
| POST | `/api/auth/register` | username 3–32 位字母数字下划线、password 8–64 字符且 UTF-8≤72 字节、nickname≤32；创建 USER |
| PUT | `/api/auth/profile` | nickname；更新本人昵称 |
| GET | `/api/books` | 新增 sourceKind=ONLINE/UPLOAD/WEB/REPO、createdFrom/createdTo=YYYY-MM-DD；默认本人及被分享内容 |
| GET | `/api/books/{id}/versions` | 历史修订、操作原因、时间与作者 |
| GET | `/api/books/{id}/versions/{revision}` | 历史快照 |
| POST | `/api/books/{id}/versions/{revision}/restore` | expectedRevision；恢复为新修订 |
| GET/PUT | `/api/books/{id}/shares` | 查询授权 / 按 username、accessRole=VIEWER/EDITOR 授权 |
| DELETE | `/api/books/{id}/shares/{userId}` | 撤销授权 |
| GET | `/api/books/{id}/export?format=md\|pdf` | Markdown 或可打印 PDF；PDF 为文本排版，不还原原 PDF 页面 |
| GET | `/api/workspace/backup` | 本人知识库 ZIP |
| POST | `/api/workspace/restore` | multipart file=ZIP，返回新 bookIds |
| GET/POST | `/api/imports` | 最近100条本人任务 / kind、url、branch、path、organize 创建任务 |
| POST | `/api/imports/{id}/retry`、`/cancel` | 本人失败任务重试 / 排队或运行任务取消 |
| GET | `/api/books/{id}/origin` | 来源、采集时间与快照元数据 |
| POST | `/api/books/{id}/suggest` | 自动分类/标签建议，返回 revision、suggestion |
| POST | `/api/books/{id}/organize` | 携带上述 revision、suggestion，按版本应用 |
| POST | `/api/books/{id}/reindex?chunking=semantic\|sentence` | 按策略创建新修订和索引任务 |
| POST | `/api/knowledge/search`、`/ask` | question、bookIds、publicOnly、searchMode、mode、topK≤30、rerank、history≤20 |
| GET/POST | `/api/conversations` | 最近200条本人对话（可按bookId筛选）/ title、bookIds、publicOnly、mode、searchMode、rerank |
| GET/DELETE | `/api/conversations/{id}` | 本人对话及消息 / 删除记录 |
| POST | `/api/conversations/{id}/messages` | question≤500；持久化本轮问题与回答，最多1000条消息 |

Python 新接口均要求 X-Internal-Token：`/internal/collect`、`/internal/classify`、`/internal/export/pdf`、`/internal/knowledge/search`、`/internal/knowledge/ask`。采集/参数错误422，修订冲突409，模型或服务失败503。生产仍不对外暴露 Python。
