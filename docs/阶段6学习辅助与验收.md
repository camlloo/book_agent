# 阶段 6：学习辅助 Agent

日期：2026-10-21。实现范围对应产品清单第六部分“学习辅助 Agent”。入口为登录后的 `/admin/learning`。

后续资料选择已统一支持多本 Book 和分类文件夹（含子分类），学习计划最多授权 50 本。最新范围验收及全量测试结果见[知识范围选择与验收](知识范围选择与验收.md)，下表保留阶段整体测试记录。

## 功能

- 创建学习路线时，填写学习目标、当前水平自评、对自评的信心、已熟悉主题、开始日期、周期、每周学习次数和单次时长；从当前用户有权访问且索引就绪的 Book 中选择知识范围。
- 周期为 1–8 周，每周 1–7 次，每次 10–180 分钟。系统先在已选 Book 中混合检索，再由 AI 根据真实片段编排周目标与每日任务。
- Java 校验模型返回的周数、每周任务数量和来源序号；只将模型给出的序号映射到本轮真实检索片段。学习任务上的来源链接跳到对应 Book 原文。
- 学习任务可打卡为“已完成”“需要复习”“已跳过”或恢复“待学习”；完成或待复习时记录 1–5 分掌握度，可补充反思。
- 学习进度由保存的任务状态计算。标记待复习或掌握度不高于 2 的任务进入薄弱点列表，按当周主题汇总。
- 至少保存一次“已完成”或“需要复习”的学习记录并评分后，可生成阶段报告，包括学习总结、当前水平估计、已有优势、薄弱主题和下一步建议，并附带路线所用的 Book 来源。
- 更新任一学习记录会清除已生成报告；生成期间记录发生变化则拒绝保存旧快照报告，提示重新生成。恢复待学习或跳过的任务不纳入低掌握度薄弱点统计。删除路线会级联删除该路线下的任务。

## 数据、权限与模型边界

- `learning_plan` 保存目标、自评、计划参数、Book 范围快照、周目标和报告；`learning_session` 保存任务日期、主题、活动、真实来源、状态、掌握度与反思。
- 两张表通过外键按用户和计划隔离。运行时 `LearningSchema` 使用 `CREATE TABLE IF NOT EXISTS` 幂等补齐已有安装，不删除数据。
- 创建路线和生成报告前后都会核验所选 Book 的权限、索引状态与 revision；范围变化返回 409。模型不能访问数据库或自行检索，RAG 和用户授权由 Java 控制。
- “当前水平”是用户自评；阶段报告结合自评、打卡与反思给出估计，并明确不是标准化测验。当前不包括正式测验、间隔重复算法、自动提醒或对 Book 内容的写入。
- 学习路线不自动发布，也不会覆盖或修改任何 Book。

## 接口

- `POST /api/learning/plans`：创建路线；需提交目标、Book ID、起点水平、自信评分、周期、频率、时长和可选开始日期/熟悉主题。
- `GET /api/learning/plans`、`GET /api/learning/plans/{id}`：列出和读取当前用户路线。
- `PUT /api/learning/plans/{id}/sessions/{sessionId}`：保存状态、掌握度和反思。
- `POST /api/learning/plans/{id}/report`：生成或更新阶段报告。
- `DELETE /api/learning/plans/{id}`：删除路线及其任务。

请求和响应字段见[接口文档](接口文档.md#16-学习辅助-agent阶段-6)。
