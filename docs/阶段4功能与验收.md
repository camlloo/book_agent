# 阶段 4：笔记与 Agent 功能及验收

日期：2026-10-18。阶段 4 于当日完成自动化与本地浏览器验证，并补充验证 Agent 翻译校对流程。阶段 5 于 2026-10-21 按用户决定撤销，相关功能不属于当前版本。

## 已完成能力

- Book 编辑页内的 AI 笔记助手可给出标题、简介、分类和标签建议，可预览正文润色，也可按指定水平解释内容。
- 可检索其他有权访问的 Book，生成关联知识结果；重复/冲突检查只报告有检索出处支持的发现，来源链接可跳到原文。
- 可对 2–10 本 Book 生成带来源的合并预览；用户明确确认后才另存为新的私有 Book 草稿，随后建立索引。
- `/admin/assistant` 支持按目标自动生成计划，也支持创建前手动编排 1–6 步。用户可调整已保存计划的步骤类型、名称、要求与顺序，也可在任意步骤后插入或移除步骤；系统校验步骤依赖，并只重置受影响步骤及后续结果，保留更早的检索证据。旧计划出现“已检索到来源、下游却说未找到出处”时，可一键保留来源并重跑后续。
- `/admin/settings` 可保存 4000 字以内的个人 Agent 偏好；偏好按账号隔离，仅影响表达方式，不代替检索证据。
- Agent 工作台根据个人 Book 的简介、分类/标签和索引状态给出整理建议。

## 数据与权限边界

AI 编辑结果先展示为预览。应用元数据或润色时校验预期 revision，并通过现有 Book 更新流程产生新修订和索引任务；过期建议返回冲突，不覆盖新内容。文件型 Book 不直接改写上传文件。计划在创建和每一步执行前后都校验 Book 权限与修订，步骤成功结果持久化；失败步骤可重试。总结、比较、起草和校对都使用前序步骤的证据；缺少证据时提示调整检索，不把处理说明当作检索问题。调整步骤时只清除本步骤与后续的旧结果。合并或起草都不覆盖来源 Book、不自动发布。长期偏好和计划只属于当前用户。

Agent 当前没有发布、删除、外网访问或任意工具能力，不会在后台自主运行。主动整理建议由 Book 元数据和索引状态规则生成；当前阶段没有间隔复习、学习进度评估或通知推送。

## Agent 校对结果异常：原因与修复

截图里的检索、总结和译稿步骤都已成功，但旧版 `compare` 会把“对照原文校对”作为独立问题再次发起 RAG 检索。这个指令描述的是处理动作，本身并不是原文主题；由于新请求没有包含前序的英文片段和中文译稿，RAG 返回不了可用出处，模型便按证据边界回复“没有检索到相关出处”。

现已改为读取所有成功前序步骤中的译稿和来源片段，再调用专门的校对操作。校对结果包含修订后的文稿、简短修改发现和可跳转的原文来源；计划界面也会阻止跳过前序步骤。Java 集成测试覆盖“不能越序执行”以及“校对请求确实包含草稿、来源片段和 fileId”。

用 Book 49 的 Python.org 文章新建并执行了一份临时 4 步翻译计划：原文检索命中 3 段，校对返回 582 字符的文稿、4 条修改发现和 3 个来源。临时计划已删除，正式 Book 内容没有被写入。结构化结果见 [compare-live-result.json](../.impeccable/review/phase4/compare-live-result.json)。之前保存的计划会保留其当时的结果；用户可以从出现错误的步骤起重置并重跑，保留前序检索证据。

后续截图显示旧计划中的第 2、3 步仍保留了错误结果；这是已保存步骤的历史结果，不会因代码修复自动重算。当前可在旧计划中修改第 2 步要求后保存，再逐步重跑；第 1 步的原文检索结果会保留，下游结果清除后重新生成。无需为了查看修复效果而重复创建计划。

针对“创建的计划不够灵活”，新增了创建前手动编排步骤，以及对已保存计划的步骤插入、排序、移除。自动生成仍可选；自定义顺序会在保存时校验“检索先于总结/比较/起草/校对、起草先于校对”，避免生成不可执行的工作流。删除、插入、排序和编辑都会保留未受影响的上游结果。新建自定义计划不调用模型规划接口。

## 浏览器验收

本地 Chrome 已验收 `/admin/assistant` 原有流程：在 Book 30《Python 入门与实践》和 Book 49 的授权范围内生成了 5 步计划，逐步执行首步并看到检索结果与原文来源；随后在 Book 30 编辑页生成并查看整理建议。桌面视口为 1440×1000，手机视口为 390×844。控制台无错误，手机下文档宽度与视口相同，管理导航在自己的横向滚动区域内浏览。本轮还用应用内浏览器验证了自定义步骤的添加、排序、移除与依赖提示，并打开旧 Python 翻译计划确认“保留来源，重跑后续”提示出现。没有保存新测试计划，也没有修改旧计划。DOM 交互与控制台检查通过；当前应用内浏览器未提供可用截图或视口设置接口，所以本轮未重新检查手机布局。

为保护正式示例 Book，整理建议只预览，没有应用。验收后删除了本轮临时计划；再次核对 Book 30 仍为 revision 1、索引 READY。结构化结果记录在 [qa-result.json](../.impeccable/review/phase4/qa-result.json)。
