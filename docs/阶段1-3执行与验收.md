## 实施约定

保留 Vue、Spring Boot、FastAPI、MySQL、MinIO 与 pgvector。现有 Books 归入现有管理员个人空间；以追加表迁移所有权和历史，不清空原库。发布仍由内容所有者确认。全库检索使用调用者的有权 Book 集合，不能先取出私有内容再在界面隐藏。

原文件历史版本保留对象，删除整个 Book 后异步清理。恢复旧版生成新修订。备份不包含密码、令牌和模型密钥，恢复创建新内容，不覆盖现有作品。

前端沿用现有蓝灰色、衬线阅读标题和三栏阅读布局；新增工作区使用来源、版本、权限等真实信息组织列表。

本文件在实施与验证完成后补充准确结果，不将计划标记为已实现。


## 用户验收入口

先打开 http://127.0.0.1:5173/login 使用现有账号登录；也可通过 /register 新建个人账号。后端升级重启后旧登录令牌可能过期，需要重新登录。

| 验收项 | 操作路径 | 预期 |
| --- | --- | --- |
| 个人空间 | 两个浏览器分别注册账号，新建各自 Book | 默认互不可见；发布内容可匿名阅读 |
| 分享权限 | Book 编辑→分享权限，输入另一账号用户名 | VIEWER 可读/提问，EDITOR 可编辑；撤销后拒绝新的私有访问 |
| 版本 | 编辑两次→历史版本→预览并恢复 | 恢复产生新修订，旧修订仍存在；文件型 Book 同时恢复原文件 |
| 导出 | Book 编辑工具条→导出 Markdown/PDF | 可下载正文；PDF 可打印并正确显示中文 |
| 备份 | /admin/settings→下载完整备份→从备份恢复 | 恢复为新的私有草稿，原稿不被覆盖，历史原文件随备份保留 |
| 网页采集 | /admin/imports→网页正文，填静态页面 URL | 保存来源、正文和分类标签；重复来源未变则显示内容未变化 |
| 仓库导入 | /admin/imports→代码仓库，填 GitHub/GitLab 项目首页 | 保存提交、目录、可读代码与技术栈；可限制分支和子目录 |
| 全库搜索 | /admin/knowledge→选择我的知识/公开书库→只搜索 | 仅返回有权且就绪的 Book，可切换全文、关键词、语义和混合模式 |
| 总结/对比 | 同页选择两本不同内容的 Book，再选择对话方式 | 回答包含结论与简短出处；点击出处聚焦相应原文 |
| 多轮与同步 | 连续追问、刷新页面或换设备登录同一账号 | 已登录对话可恢复，历史和范围归属当前账号 |

参考采集地址：`https://www.python.org/doc/essays/blurb/`、`https://github.com/octocat/Hello-World`。网络失败会在任务中显示原因，可重试或取消。

## 当前范围

支持静态网页正文、github.com/gitlab.com；不运行网页JavaScript或仓库代码。私有仓库需要配置具备权限的服务端令牌，真实联网验收采用公开仓库。语义分块和重排会增加模型调用；不可用的重排明确回退融合排序。总结与比较依据实际检索片段，并非全库完整审计。

备份500本/100MB压缩/256MB展开；单文件20MB；检索范围最多5000本、每轮最多30段；对话最多1000条消息。同步为服务端保存与再次读取，没有离线合并和实时共同编辑。升级以前没有记录的历史无法追溯。

功能已达到阶段 1–3 验收范围。阶段 4 已完成，见[阶段 4 功能与验收](阶段4功能与验收.md)。知识图谱阶段已按用户决定撤销，不属于当前版本。
